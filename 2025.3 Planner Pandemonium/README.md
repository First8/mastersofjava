## Unplannable Planner

### Omschrijving voor de Gamemaster

De opdracht bestaat uit een vervelende opdrachtgever die steeds met een nieuwe requirement komt, die de vorige in de weg zit

Stap 1: Maak het begin van de planner (addAppointment) met een check voor invalid appointments en overlapping appointment

Stap 2: Maak een check voor het tegenhouden van overlappende appointments

Stap 3: Maak een check die afdwingt dat de begin tijd voor de eind tijd moet zijn

Stap 4: Feature dat je alleen in de ochtend (08:00) tot einde van de middag (17:00) afpsraken kan inplannen

Stap 5: Feature die ervoor zorgt dat er GEEN afspraken op maandag/dinsdag ochtend + vrijdagmiddag kunnen worden ingepland

Stap 6: Speciale dag waarbij er geen afspraken kunnen worden ingepland (de 3e woensdag van mei)
