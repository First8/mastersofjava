## Smorgasbord

### Omschrijving voor de Gamemaster

Deze opdracht bestaat uit 3 kleine opdrachten waarbij de spelers een fix moeten toepassen om de tests te laten slagen. 

De opdrachten bestaan uit:
1. StringJoin: een opdracht waarbij momenteel een bug is waardoor de output niet is wat je zou verwachten bij een stringjoin
2. DateTimeFormat: met de aangeleverde code krijg je een interessante stack trace 'Missing YearOfEra' wat vrij onduidelijk is
3. FibonacciSequence: de opdracht bevat in het begin een methode die een Fibonacci Sequence maakt, echter ontbreekt er wat logica waardoor hij niet doet wat zou moeten
